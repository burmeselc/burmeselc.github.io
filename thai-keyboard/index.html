Thai Keyboard

ローマ字キーからタイ文字を入力する補助キーボード。同じキーを続けて押すと候補が切り替はります。母音は入力順序どほりに挿入します。

タイ文字の入力

入力待機中入力文字はこのページ内だけで処理します。

入力配列

Shift：大文字側の文字

` または右矢印で候補を確定（文字を追加しません）。@ 連打で ่ → ้ → ๊ → ๋。別のキーで自動確定します。記号類は通常どほり入力できます。

同じキーを使ふときK → ค、KK → ข、K`K → คค。時間制限はありません。
母音は文字順に入力eka → เกา。自動の並べ替へは行ひません。y = ไ、Y = ใ、W = โ。
数字・記号1–0 は ๑–๐。ASCIIモードなら通常の数字・アルファベットを入力できます。. , : ; - = " ( ) は通常モードでも維持します。
特殊なタイ語記号を挿入

あまり使はれない文書記号を必要な位置に直接入力します。
