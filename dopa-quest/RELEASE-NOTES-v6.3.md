# DOPA QUEST v6.3 — 学習中の校閲メモ導線

2026-10-12 JST。表示版 v6.2 → v6.3。

- シャン語単語帳に実装済みの校閲メモ機能を単語カード裏面、クエスト正答・誤答後に接続した。全入口が同じ端末内保存 `dopa_shan_editorial_notes_v1` を使用する。

- 既存の保存キー `dopaQuestV5_profile`、カードID、Firebase、XP、復習期限、原データ、語義正式承認状態は不変。表示版数とPWAキャッシュ識別子のみ更新。
- オーディオAPIや自動再生への変更なし。実機iPhoneに於けるバックグラウンド音楽との共存は継続して要確認。
- 追加11,505親語形のうち、暫定分類4,949件、境界983件、未分類5,526件、残り65の再点検から47件保留（うち19件修正候補、28件意味境界）は維持。
