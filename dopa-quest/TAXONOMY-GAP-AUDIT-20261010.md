# DOPA QUEST 語彙分類ギャップの診断（2026-10-10）

## 調査範囲と限界

PR #20 の旧大領域01～18に分類された P/R 親カード6,468件を基準とする。暫定的に中分類まで分類された3,999件と、保留2,469件を区別する。この数は原辞書確認済みの件数を意味しない。旧 M/H カード、既存のシャン語語義子カード、追加CSVの候補は対象外。

保留の内訳：初回確認後の詳細範囲未確定2,223、親定義が複数領域にまたがる54、元の大分類と訳語の相違20、中分類の適用範囲に疑義16、その他57、第18領域の保留99、合計2,469。第18領域の99件は、既存の独立台帳（12ビルマ語・87シャン語）に属する。2,223件は未完了の集合であって、カテゴリ不足が2,223件あると判断したものではない。

## 確認できた分類体系の不足と設計変更

大領域18件を増減・付け替へせず、中分類77件に次の5枝を新設して82件とする。中分類は見出しとして試験画面に現れるが、語の割当はまだしない。

| 新ID | 中分類 | 根拠・使ひ分け |
|---|---|---|
| 09.05 | 国・地域・地名 | 国・都市・集落・地域名のための受け皿。自然地形そのものは01 |
| 12.05 | 文学・物語・詩歌 | 既存保留の小説・詩・昔話・諺など13件の候補 |
| 12.06 | 歴史・歴史叙述 | 既存保留の歴史・国史など3件の候補 |
| 13.05 | 言語名・言語変種 | 既存の発話・書記・情報・教育の4枝では言語名そのものを扱ひにくい |
| 17.07 | 派生・名詞化・語形成 | 既存の格・時制相・接続等の6枝では名詞化接辞の受け皿が不明確 |

分野タグに `field:literature`（文学）・`field:history`（歴史）を追加する。語義本文から根拠が確認できる場合のみ付す。特定の文学ジャンル名だからといって勝手に宗教タグ等は付さない。

既存保留の16件は `data/study-taxonomy-gap-proposals-v1.json` に、元カードID・元表記・訳語・旧大分類・提案中分類をすべて保存した（ビルマ語9件、シャン語7件）。これは**語義の再分類ではなく、配置先の候補**であり、詳細学習の件数は3,999件のまま。原辞書の照合後にのみ正式な分類メタデータへの昇格を検討する。

## 小分類の試験設計

`data/study-small-category-proposals-v1.json` に、文学の下位4件（小説・散文、物語・説話、詩歌、文学一般・諺）と地名の下位3件（国名、都市・集落名、地域・行政地名）を構想として追加した。

小分類7件はいづれも **design-only** であり、現行の絞り込みUI・出題・デッキには適用しない。他の中分類すべてへ機械的に小分類を生やさない。1語だけの小分類も語彙一覧での学習には有用であり、四択を構成できるかどうかは独立した条件で判断する。

## 語義分割と分類変更を混同しない

- 複数領域：シャン語 `ၵႂၢမ်း`「言葉・言語・歌」、`ၼမ်ႉ`「水・川・純度・本質」、ビルマ語 `-ဘူး`「否定語尾・助数詞」などは、同一親カードに無理に中分類を一つ付けない。語義単位での分割を要検討。
- 大分類の不整合：ビルマ語 `နွေရာသီ`「暑季」が旧06、`မှန်ဘီလူး`「虫眼鏡」が旧06など。候補中分類が既に存在するので、新しい中分類は必要ない。元のカードIDは保持し、校閲後に分類対応を改める。
- 機能語：`ထား`「置く／結果状態の補助動詞」、`-နဲ့`「共格・道具格／禁止」などは語義・機能の範囲を区別する。17.07への自動移送はしない。
- 元18大領域の保留には「中将」「車輪」「ガジュマル」なども存在する。これらは18を一般的な保留箱とみなしたことに起因する可能性があり、既存の01・02・09・11等への再配置を優先して確認する。

## 次回からの実作業

1. この診断の次は、本来のPR #20語彙分類・校閲へ戻る。まず既存の明確な分類境界問題16件を原出典と照合し、新12.05・12.06へ昇格できる語義を判定する。
2. 旧大分類の不整合20件＋詳細適用範囲の不一致13件を、カードIDを維持したまま個別審査する。
3. 複数領域にまたがる親定義と文法機能を語義ごとに分離する。既存シャン語の語義子カードと突合し、新IDを無用に作らない。
4. 2,223件の「詳細未確定」と第18領域99件を、追加候補CSVの原資料照合と重複解消を踏まへ、領域ごとに仕分ける。保留を一括して誤分類扱ひにはしない。
5. 確認できた語義を段階的に分類メタデータへ反映し、同義語衝突・四択の成立・デッキID・学習履歴不変をテストする。
6. タグ／中分類／小分類から1語でも閲覧・復習できる一覧機能を実装する。四択に4つの識別可能な候補が必要な条件は緩めず、一覧閲覧を解答履歴として記録しない。

この変更は試験ブランチの分類体系・設計台帳のみ。本番 `main` への統合、元デッキ、過去の学習履歴は変更しない。
